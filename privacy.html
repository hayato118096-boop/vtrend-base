プライバシーポリシー

VTrend Base（https://hayato118096-boop.github.io/vtrend-base/）　最終更新：2026年11月11日

VTrend Base は、VTuber のトレンドを調べたり、自分の YouTube チャンネルの数字を見たりするためのサイトです。このページでは、「マイチャンネル」で Google にログインしたときに、どの情報をどう使うかを説明します。

1. ログインで見せてもらう情報

  • YouTube のチャンネル情報と動画の一覧（YouTube Data API・読み取りだけ）
  • YouTube アナリティクスの数字（再生・視聴時間・インプレッション・流入元・年齢層など。YouTube Analytics API・読み取りだけ）

動画の投稿・編集・削除、コメント、チャンネルの設定の変更など、書き込みは一切しません。

2. 情報の使い道

  • ログインした本人に、自分のチャンネルの数字・総評・改善のヒントを画面で見せるため
  • AI の総評を作るため（下の「4」）

広告や販売には使いません。ほかの人に見せたり、渡したりもしません。

3. 保存する場所

  • 見ている端末のブラウザ：取ってきた数字、ログイン中であることの印、入力した「自己プロデュース」
  • 保管庫（運営者の Google アカウントの Google Apps Script と Google ドライブ）：ログインしたままにするための更新用の鍵、入力した「自己プロデュース」、AI の総評。どの端末で開いても同じ内容を見られるようにするためです。

4. AI（Google Gemini）について

総評を作るときは、チャンネルの数字・動画のタイトルと説明欄・アイコンとサムネイルの画像・入力した自己プロデュースを、Google の Gemini API に送ります。総評は1つのチャンネルにつき1日1回までです。

5. Google のデータの扱い

Google API から受け取った情報の使い方は、Google API サービスのユーザーデータに関するポリシー（限定的な使用の要件を含む）に従います。あわせて YouTube 利用規約 と Google プライバシーポリシー も適用されます。

6. やめたいとき・消したいとき

  • マイチャンネルの「ログアウト」を押すと、その端末のログインと保管庫のログインの印が消えます。
  • アカウントの「設定」→「消す」で、その端末に保存した数字と入力が消えます。
  • Google アカウントの「サードパーティ製のアプリとサービス」 から VTrend Base のアクセスを取り消すと、更新用の鍵は使えなくなります。
  • 保管庫に残っている入力・総評を消したいときは、運営者に連絡してください（Google のログイン画面に出ているサポートの連絡先）。

7. このページの変更

内容を変えるときは、このページを書き直し、上の「最終更新」の日付を変えます。
